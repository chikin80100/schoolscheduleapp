# 学校時間割アプリ

週表示 / 月表示を切り替えられる時間割の PWA と、**次の授業の 10 分前に教科と持ち物をプッシュ通知**する
Cloudflare Worker。iPad でホーム画面に追加すると、ネイティブアプリのように使えます。

HTML / CSS / JavaScript のみで実装しており、ビルドツールもフロントエンドの依存パッケージもありません。

## 時程

| 時限 | 時刻 | 通知 |
|---|---|---|
| 1 | 8:50–9:40 | 8:40 |
| 2 | 9:50–10:40 | 9:40 |
| 3 | 10:50–11:40 | 10:40 |
| 4 | 11:50–12:40 | 11:40 |
| 昼休み | 12:40–13:20 | — |
| 5 | 13:20–14:10 | 13:10 |
| 6 | 14:20–15:10 | 14:10 |
| 7（火・木のみ） | 15:20–16:10 | 15:10 |

月・水・金は 6 時限、火・木は 7 時限。授業 50 分・休憩 10 分・4 限と 5 限の間は 40 分の昼休み。
通知の「何分前」は設定画面から 1〜60 分の間で変えられます。

## 主な機能

- **週表示 / 月表示の切り替え** — 週は時限 × 曜日のグリッド、月はカレンダーに科目チップ
- **教科カードのドラッグ登録** — 専攻ごとのプリセットをコマにドラッグ。コマ同士のドラッグで入れ替え、
  ゴミ箱にドロップで削除。iPad でも動くよう Pointer Events で自前実装しています
  （タップで選んでコマをタップする置き方もできます）
- **カードの編集** — 持ち物（初期状態は空）・教室・先生・色。持ち物はそのまま通知本文に載ります
- **日付ごとの上書き** — 週テンプレートを基本にしつつ、特定の日だけ休講・変更にできます
- **プッシュ通知** — Cloudflare Worker の Cron Trigger が毎分チェックし、該当する端末にだけ送信
- **オフライン対応** — Service Worker がアプリシェルをキャッシュ。時間割は端末内 (localStorage) に保存

  論理国語 / 国語表現 / 歴史総合 / 政治・経済 / フードデザイン / 体育 / 美術表現 / プロゼミ２ / LHR / 実習

- **電気専攻** — 電力技術 / 電気回路 / 電気実習 / 電力技術Ｂ / 電子技術 / 電気製図 / 電気機器 / 電気回路Ｂ

## セットアップ

前提: Node.js 18 以上と Cloudflare アカウント。

```bash
npm install
npx wrangler login
```

### 1. D1 データベースを作る

```bash
npx wrangler d1 create timetable
```

表示された `database_id` を `wrangler.toml` の `REPLACE_WITH_YOUR_D1_DATABASE_ID` に書き込み、
テーブルを作成します。

```bash
npm run db:init          # 本番
npm run db:init:local    # ローカル開発用
```

### 2. VAPID 鍵を作る

Web Push の送信元を証明する鍵ペアです。

```bash
npm run keys
```

出力された 2 つの値を登録します。

```bash
npx wrangler secret put VAPID_PUBLIC_KEY
npx wrangler secret put VAPID_PRIVATE_KEY
```

`wrangler.toml` の `VAPID_SUBJECT` を自分の連絡先（`mailto:` か `https:`）に書き換えてください。
ローカル開発では、リポジトリ直下に `.dev.vars` を作って同じ 2 つを書きます（このファイルは Git 管理外）。

```
VAPID_PUBLIC_KEY=B...
VAPID_PRIVATE_KEY=...
```

### 3. ローカルで動かす

```bash
npm run dev            # http://127.0.0.1:8787
```

静的ファイルの配信・API・Cron がすべて 1 つの Worker で動きます。

### 4. デプロイ

```bash
npm run deploy
```

## iPad でアプリとして使う

1. Safari でデプロイした URL を開く
2. 共有ボタン → **ホーム画面に追加**
3. ホーム画面のアイコンから起動する
4. 右上の ⚙ → 専攻を選ぶ → **通知を有効にする** → **テスト通知** で受信を確認

> **Web Push の条件**: iOS / iPadOS 16.4 以降で、かつ「ホーム画面に追加」したアプリから開いた場合にのみ
> 通知が使えます。Safari のタブで開いている状態では通知を有効にできません。
> 通知の許可はボタンのタップから要求する必要があるため、設定画面のボタン以外では要求しません。

## 仕組み

```
public/            静的ファイル（そのまま配信される）
  js/schedule.js   時程の定義 — フロントと Worker が共有する唯一の情報源
  js/timetable.js  週テンプレート＋日付上書きの解決（同じく共有）
  js/dnd.js        Pointer Events によるドラッグ&ドロップ
  sw.js            Service Worker（キャッシュ / push / notificationclick）
worker/
  index.js         /api/* と Cron Trigger、静的アセットへのフォールバック
  webpush.js       VAPID(ES256) と aes128gcm 暗号化を WebCrypto だけで実装
```

- 時間割は端末の localStorage が正。通知を有効にした端末だけ、購読情報と時間割を D1 に同期します
  （通知を使わなければサーバには何も残りません）。
- Cron は UTC で `* 23 * * *` と `* 0-6 * * *`、つまり日本時間の 8:40〜15:10 を毎分チェックします。
  実際に送るかどうかは Worker が曜日・時刻・休講設定を見て判定します。日本に夏時間はないため
  UTC+9 の固定オフセットで計算しています。
- 送信先が 404 / 410 を返した購読は自動的に削除します。

### API

| メソッド | パス | 用途 |
|---|---|---|
| GET | `/api/vapid` | VAPID 公開鍵を返す |
| POST | `/api/sync` | 購読情報と時間割を保存する |
| DELETE | `/api/sync` | 購読情報と時間割を削除する |
| POST | `/api/test` | その端末にテスト通知を送る |
| GET | `/api/dry-run?at=...` | 指定時刻で通知処理を試す（`ALLOW_DRY_RUN="true"` のときだけ） |

## 動作確認

```bash
npm test        # 時程・通知文面・VAPID 署名・本文の暗号化(RFC 8291 の往復)を検証
```

Cron の動きを手元で試すには、`wrangler.toml` の `ALLOW_DRY_RUN` を `"true"` にして:

```bash
npm run dev
# 月曜 3限(10:50)の10分前 = 日本時間 10:40 = UTC 01:40
curl "http://127.0.0.1:8787/api/dry-run?at=2026-08-31T01:40:00Z"
```

Cron ハンドラ自体を発火させる場合:

```bash
curl "http://127.0.0.1:8787/cdn-cgi/local/scheduled?cron=*+0-6+*+*+*"
```

アイコンを作り直す場合は `npm run icons`（Python 3 のみ、追加パッケージ不要）。
